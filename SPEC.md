# FontToggleShelf — specification

**Tagline:** Browse font folders anywhere on disk, preview them with your own text, and switch fonts on or off without a subscription.

**Category:** Font Management

**Inspired by (paid):** RightFont ($59 /year)

**Frameworks:** SwiftUI, AppKit, CoreText, UniformTypeIdentifiers, ServiceManagement

**Donation URL (Support button):** https://ko-fi.com/leodavidai

## Spec

(1) What the paid app does and evidence of demand. RightFont is a font manager for macOS that lists installed fonts and fonts kept in folders or cloud drives, previews them with sample text, lets designers activate and deactivate fonts without copying them into the Fonts folder, and syncs font libraries across machines. It sold as a one-time license for years and recently moved to an annual subscription that locks the app until renewed, which triggered requests on Reddit for an open-source replacement. Font Book covers only installed fonts and has weak folder support, so a free folder-based activation tool has clear demand among designers and developers. Our clean-room version is a focused font library browser with activation.

(2) Feature set for our version. The app manages font libraries, which are folders the user adds from anywhere on disk, for example a Downloads fonts folder, a Dropbox or iCloud Drive folder, or a project assets folder. For each library it scans recursively for font files with extensions ttf, otf, ttc, dfont and woff2 is ignored. Each font file is read with CoreText to get the family name, style name, PostScript name, format and number of glyphs. The main window shows a sidebar listing All Installed, each library folder, Activated, and Favorites. The content area shows font families grouped from their files, with a live preview line rendered in that font using a sample text field and a size slider the user controls. A detail pane shows family, style, PostScript name, file path, format, a longer multi-line sample paragraph, and a pangram plus digits and punctuation line. Each family and each individual style has an activation toggle. Activation uses CoreText font manager registration of the file URL with session scope so the font becomes available to every app until logout without copying the file, and a Persistent option that uses persistent user scope so it stays active after restart. Deactivation unregisters the same URL. Installed system fonts from the user and system Fonts folders are listed read only under All Installed with a Reveal in Finder action and cannot be deactivated. Search filters by family, style or PostScript name. Favorites are stored by PostScript name. A duplicates filter lists PostScript names that appear in more than one file. The user can drag a folder onto the sidebar to add it as a library. A Collections feature is out of scope for the first version.

(3) UI spec. This is a regular window app, not a menu bar app, with a NavigationSplitView of three columns. The toolbar holds a search field, a grid or list toggle, the sample text field, the size slider, and an Add Library button. The sidebar context menu offers Rescan, Reveal in Finder and Remove Library. Font rows show the family name in the system font on the left and the preview text rendered in the font on the right, with a green dot when activated. The detail pane has an Activate button, a Persistent toggle, a Favorite star and a Reveal in Finder button. Settings has fields for default sample text, default size, a toggle to activate the whole family when one style is activated, and launch at login. Empty states: no libraries yet shows a large dashed drop zone with text Drop a folder of fonts here or click Add Library; a library with no fonts shows No font files found in this folder. Keyboard shortcuts: Command F for search, Command Shift A toggles activation of the selection, Command D favorite, Command R rescan.

(4) Technical approach. Libraries are stored as security-scoped bookmarks in UserDefaults so folders outside the sandbox remain readable after relaunch; call start accessing security scoped resource before scanning and stop after. Scanning uses FileManager enumerator on a background task and produces an array of font records encoded with Codable and cached in Application Support so the window opens instantly. Font metadata comes from CTFontManagerCreateFontDescriptorsFromURL and CTFontDescriptorCopyAttribute for family, style and PostScript names. Previews use NSFont created from the descriptor at the chosen size, or for files that are not yet activated create the font with CTFontCreateWithFontDescriptor from the URL-based descriptor which works for rendering inside this process without registration. Activation calls CTFontManagerRegisterFontURLs with session scope or persistent scope and collects errors from the completion handler; deactivation calls CTFontManagerUnregisterFontURLs with the same scope. The activated state is derived at launch by checking whether each PostScript name resolves through CTFontCreateWithName with a matching URL attribute, and persisted as a fallback set of PostScript names in UserDefaults. Folder changes are watched with a DispatchSource file system object source on the folder descriptor and trigger a rescan after a short debounce. Launch at login uses SMAppService.

(5) Edge cases and error handling. A font file that is corrupt or unsupported shows a warning icon and the CoreText error text instead of a preview. Registering a font whose PostScript name is already active from another file fails with a conflict error that is shown inline with a button to reveal the other file. Session activations vanish after logout, so the sidebar Activated section notes which ones are session only. Removing a library deactivates its session fonts first. Very large folders with thousands of files must scan incrementally and show a progress indicator in the sidebar row. If a bookmark becomes stale because the folder moved, show a Relocate button that opens a folder picker. Preview text that includes characters a font lacks shows fallback glyphs, so the detail pane also shows the glyph count. Never move or delete the user's font files.
