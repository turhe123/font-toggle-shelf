Features

Font management without the subscription.

Everything works from the folders you already have, using only Apple frameworks and no network access.

Libraries from any folder

Add Downloads, Dropbox, iCloud Drive or a project's assets folder. Folders are scanned recursively for TTF, OTF, TTC and DFONT files and watched for changes.

Live previews with your text

Every family renders in its own font using your sample text and a size slider from 8 to 120 pt, in list or grid view. Fonts preview even when they are not activated.

Activate without copying files

Toggle a whole family or a single style. Fonts are registered by file URL for the current session, or persistently across restarts. Your files are never moved or deleted.

Metadata and duplicate finder

See family, style, PostScript name, format and glyph count for every face. The Duplicates view lists PostScript names found in more than one file.

Clear conflict and error handling

If the same PostScript name is already active from another file, the app says so inline and offers to reveal that file. Corrupt files show the CoreText error instead of a preview.

Search, favorites, shortcuts

Search by family, style or PostScript name, and star favorites. Use Cmd-F to find, Cmd-O to add a library, Cmd-R to rescan and Shift-Cmd-A to toggle activation.

Install

Up and running in a minute.

FontToggleShelf is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download FontToggleShelf-macOS.zip and unzip it.
  2. Move FontToggleShelf.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/FontToggleShelf.app
  4. No special permissions are required macOS may ask once for access if you add a protected folder such as Documents, Desktop or iCloud Drive.

FAQ

Questions, answered.

Is FontToggleShelf really free and open source?

Yes. It is released under the MIT license and the full source is on GitHub. There are no accounts, no analytics and no third-party dependencies, and it makes no network calls.

What permissions does it need?

None of the privacy permissions such as Accessibility or Screen Recording. It reads only the folders you add and the standard font folders, and the optional Launch at login setting appears under Login Items in System Settings.

Where is my data stored?

Your font files stay where they are. Library folders are remembered as security-scoped bookmarks, settings live in UserDefaults, and a scan cache is kept in ~/Library/Application Support/FontToggleShelf/.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to get past Gatekeeper, or build it yourself from source with Xcode.

Was this written by AI?

Yes. FontToggleShelf was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
